## 一、申请背景与目标

**目标（一句话）**：为"海淀区京张走廊 AI 创新带"城市设计项目获取《海淀区京张铁路遗址公园沿线（人工智能创新街区重点地区）HD00-1601 等街区控制性详细规划（2022—2035）》批准成果（图则/用地规划图/指标表/电子矢量），用途为**规划研究与方案合规校核**（非商业开发、不公开出版或展示），对应项目缺口 GAP-CONTROL-001（控规指标）、GAP-BOUNDARY-001/002（范围线，视图则内容而定）、GAP-ROAD-001（道路红线）。

已批准控规成果依法应主动公开；主动公开渠道不足部分（原公示条目已从公示系统下架，见方案 §三 A2/R7）以**依申请公开**兜底。本申请包即为此路径的完整可提交文书。

### 5.2 答复 4 种情形处置决策树

```
收到答复告知书
│
├─ 情形 A：告知"已主动公开"（条例36条）
│   └─ 请求指明获取途径（具体栏目/URL）→ 转主动公开渠道抓取并登记；
│       如公示条目已下架，要求提供其存档或复制件
│
├─ 情形 B：同意公开，提供图则/用地规划图（图片版）
│   ├─ 接收 → 归档登记（§六）
│   └─ 如仅提供图片版图则而无指标表/矢量：
│       └─ 就"指标表电子数据""矢量数据"另行单独申请（方案 §五 提示）
│
├─ 情形 C：同意公开，提供电子版矢量数据（SHP/GeoJSON）+指标表
│   └─ 接收 → 核验坐标基准（EPSG:4548/CGCS2000）→ 登记（§六）
│
└─ 情形 D：不予公开 / 不属于公开范围 / 信息不存在
    ├─ 1) 索要书面理由（条例36条须说明理由并告知救济途径）
    ├─ 2) 论证"批准的控规图则与指标表非涉密，可依法分离公开"
    │      （测绘法34条、测绘成果管理条例16/17条、自然资发〔2020〕95号：
    │        涉密的是≤1:1万地形底图，非控规图则本身）
    ├─ 3) 不服 → 行政复议 / 行政诉讼（条例51条）；
    │      或向市政府信息公开主管部门投诉举报
```
