## 一、概述

京张走廊（统筹研究范围 bbox 116.310–116.395, 39.935–40.030）设施底数
GAP-SERVICE-001 缓解：将北京开放平台 3 个海淀子集（幼儿园名录 284 行 /
社区卫生服务中心 222 行 / 社会公用充电站 196 行）逐条高德地理编码，
GCJ-02→WGS84 转换后按走廊 bbox 求交，并与高德 POI（facility_poi_gaode.geojson）
做多源对照。

## 二、数据与方法

- **开放平台数据集**（下载见 `data/sources/beijing-data-open/`）：
  - 幼儿园名录（市教委）：字段 区/幼儿园名称/办园性质/举办者/幼儿园地址
  - 社区卫生服务中心（站）（市卫健委）：机构名称/地址/…（原 GBK，子集已转 UTF-8）
  - 社会公用充电站（市城管委）：运营商/充电站点标准名称/区县具体地址/快慢充接口数
- **地理编码**：`scripts/geocode_beijing_open_data.py`，高德 `/v3/geocode/geo`
  （address + city=北京），限速 ≥1s/请求、失败重试 3 次退避、配额错误停跑；
  结果 GCJ-02→WGS84 近似逆变换；派生 CSV 新增
  `source_row`（原子集 1 基行号，可追溯）/ `geocode_query` / `lon_wgs84` /
  `lat_wgs84` / `geocode_status`；断点续跑（已编码行跳过，不重复消耗配额）。
- **走廊交集**：`scripts/corridor_intersection_and_comparison.py`，以走廊 bbox
  为准分桶 in/out/not_geocoded；一致性校验 in+out==编码成功、成功+未编码==总数。

**差异说明**（口径不同，数量不可直接相减）：
1. **范围/粒度**：开放平台=正规机构/站点名录（注册机构、社会公用站点）；高德 POI=全量点位库，school 类含高校/中小学/幼儿园/培训机构，medical 类含诊所/药店/口腔门诊/医疗用品店等更广分类，charging 类含个人/专用充电桩——因此高德数量普遍大于开放平台名录。
2. **口径用途**：开放平台名录适合作"设施是否有/在哪"的权威底数（官方公开数据）；高德 POI 适合作点位密度/覆盖参考。两源互证：走廊内均存在三类设施，无"完全缺失"情形。
3. 数量比例（开放平台走廊内/高德）：幼儿园 72/207≈0.35、社区卫生 61/200≈0.31、
   充电站 56/187≈0.30——高德 school 类含高校/中小学/幼儿园/职校/培训（207），
   范围远大于幼儿园名录，比值低符合预期；医疗/充电高德类别同样更宽泛。
   注：本报告高德 school 数（207）为 2026-08-18 采用 city=海淀区 区级查询补拉
   后的结果（较 city=北京市 的 101 显著提升，中学 7→19，零地名污染）。

## 六、GAP-SERVICE-001 缓解程度判断

**部分缓解→显著缓解**：走廊内三类设施（幼儿园 72 / 社区卫生 61 / 社会公用充电站 56）
已获得官方名录 + 坐标定位 + 走廊内清单 + 点位 geojson，可与高德/OSM 底数交叉使用。
- 教育设施：开放平台名录（72 走廊内）叠加高德 school（207，含高校/中小学/幼儿园）
  与 OSM 设施底数，可支撑"15 分钟生活圈/教育设施配套"类分析与方案叙事；
- 医疗设施：社区卫生服务中心（61 走廊内，含高校附属社区中心）构成基层医疗底数；
- 充电设施：社会公用充电站（56 走廊内）支持职住服务/新能源场景。
- 剩余缺口：设施**服务半径/质量/运营状态**（名录无此类字段）、非名录类商业服务设施
  仍依赖 POI 底数；正式提交物如需"官方设施清单"级证据，本批数据已可支撑（official 级名录）。

## 七、局限

1. **编码失败 3 条**：复合楼层/车位地址无法编码，未获坐标，已列入清单；其中
   中国电子大厦（丹棱街）实为走廊内（海淀中关村），因地址含"海定中街"错字+车位号
   编码失败——若需此点可手工补坐标。
2. **地址文本精度**：开放平台地址为文本字段，编码精度受地址完整度影响（数米至数十米）；
   个别机构同址多条（如"北京明天幼稚集团"总部与各园），属数据本身特性。
3. **时效**：数据集为平台发布快照（下载日 2026-08-18），机构撤并/站点搬迁后可能过期；
   高德 POI 为 2026-08-15 抓取快照。
4. **口径差异**：多源对照仅作数量互证，不直接相减（见 §5 差异说明）。
5. **坐标转换**：GCJ-02→WGS84 近似逆变换，数米级误差；不得用于红线/审批级精度用途。
