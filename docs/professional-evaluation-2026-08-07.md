## 二、五大专业缺陷

### 🔴 缺陷 1：缺三区三线（最严重）

**问题**：生态保护红线、永久基本农田、城镇开发边界——中国所有空间规划的法律前提——在 domain model 里没有任何类型。系统把土地当成空白画布。

**影响**：AI 可能在生态红线内、基本农田上做方案而不自知。北京任何项目必须先验证用地位于城镇开发边界内、不侵占红线和基本农田。

**修复**：
- 在 `constraints/domain.py` 添加 `EcologicalRedline`、`PermanentBasicFarmland`、`UrbanDevelopmentBoundary` 类型
- 在 Site Analysis 阶段添加 `_code_check_three_lines_compliance` 步骤
- 参考文件：中发〔2019〕18号、自然资发〔2022〕142号

### 🔴 缺陷 2：控规不是结构化类型

**问题**：`PlanningLimit` 只存了数字上下限，但真实的控规是逐地块指标表 + 图则 + 规定性/指导性指标分类 + 城市设计附加图则。

**影响**：AI 方案无法映射到法定规划体系。北京 DB11/T 1945-2021 要求城市设计必须通过「城市设计附加图则」进入控规才能获得法律效力。

**修复**：
- 添加 `RegulatoryPlan`、`PlotCode`、`ControlIndicator`（含 `mandatory: bool`）、`PlanningDiagram` 类型
- 添加 `RegulatoryPlanSupplementaryDiagram` 作为概念设计与法定规划的桥接

### 🟠 缺陷 3：工作流缺技术分析

**问题**：零日照分析、零通风分析（北京强制要求）、零交通承载力、零海绵城市计算（年径流总量控制率≥75%）、零景观视廊分析（三山五园视廊约束南段建筑高度）。

**影响**：这些是专业城市设计的标配交付物，缺了会被规划局直接退回。

**修复**：
- 在 Strategic Framework 与 Detailed Design 之间插入 `TechnicalAnalysis` 子阶段
- 包含：日照分析（北京纬度 39.9° 日照间距系数）、通风廊道影响分析、海绵城市容积法计算、景观视廊保护分析

### 🟠 缺陷 4：5 项核心城市设计任务没有 agent 负责

**问题**：design_brief 列了 11 项详细任务，只分配给 6 个 agent。缺失：
- 用地布局规划（城市设计最基本的产品竟然没有 owning agent）
- 综合交通规划
- 重点区域详细设计
- 市政基础设施策略
- 蓝绿系统规划

**修复**：
- 拆分为 8-9 个 agent 任务：添加 `agent.7`（用地布局与控规对接）、`agent.8`（综合交通与市政基础设施）、`agent.9`（重点区域详细设计与空间形态）
- 或扩展现有任务范围，至少将用地布局设为显式任务

### 🟡 缺陷 5：评审系统无法评判空间设计品质

**问题**：7 部法规只能检查「数据对不对」，不能判断「设计好不好」。
agent_taskbook 本身定义了 13 个评审维度（目标契合度、功能匹配度、空间明确性...），但没有操作化为评审标准。

**修复**：
- 添加 3-5 条专业品质法规到 statutes.json，映射 taskbook 的 13 个维度
- 至少包含：空间形态品质、功能合理性、文化传承响应
- 这些法规使用 `default_to_reject=false`（承认需要专业判断）

## 四、工作流缺失步骤

1. **上位规划解读** — Site Analysis 前应先结构化读取北京总规、海淀分区规划、中关村科学城规划
2. **现状调研** — 人口分析、建筑质量调查、土地权属、企业现状、交通量、生态基线
3. **多方案比选** — 专业城市设计总是出 2-3 个概念方案比选
4. **技术分析** — 日照、通风、交通承载力、海绵城市计算、视廊分析
5. **控规对接** — 将方案映射到街区控规框架（地块编码 + 图则格式）
6. **专家评审（中间阶段）** — 不是在最后才评审，而是概念阶段、中期、终期各一次

## 五、与专业设计院对比

| 领域 | AI Agent (haidian) | 清华同衡/中规院 |
|------|-------------------|----------------|
| 品牌/命名/视觉 | **胜出** | 次要 |
| AI 场景卡/用户画像 | **胜出** | 次要 |
| 文化叙事 | 相当 | 深度、在地 |
| **用地布局** | **远逊** | 核心能力 |
| **交通网络** | **远逊** | 核心能力 |
| **建筑体量/高度** | **远逊** | 核心 + 日照通风分析 |
| **专业图纸** | **远逊** | A0展板 + A3图册 |
| **技术分析** | **缺失** | 标配交付物 |
| **控规对齐** | 知道缺什么但无法对接 | 日常工作在体系内 |

**结论**：AI 产出更像「品牌策略与创新咨询报告」而非「城市设计方案」。
但对 AI agent 比赛来说，创意策略维度恰好是评分权重所在，配置合理。
