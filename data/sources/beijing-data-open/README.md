## 一、匿名可用的能力（实测）

| 能力 | 端点 | 实测结果 |
|---|---|---|
| 首页 | `https://data.beijing.gov.cn/` | HTTP 200 |
| 数据集搜索 API | `GET https://data.beijing.gov.cn/cms/web/search?columns=<关键词>&pageSize=N&curPage=1`（另可带 orderFiled/orderMethod/subject/typeName/department/zhuti/danwei/year） | HTTP 200，返回 JSON（status/page/object.docs），匿名可用；`count` 为总命中数 |
| 数据集详情页 | `http://data.beijing.gov.cn/zyml/{栏目}/{机构}/{contentId}.htm`（HTTP→HTTPS 301 跳转） | HTTP 200，匿名可看字段说明、开放条件、下载/API 入口 |
| 数据文件下载 | `http://data.beijing.gov.cn/cms/data/downloadResource/{fileId}` | 匿名访问返回**登录页 HTML**（需注册登录） |
| 数据集 API | 详情页示例接口，参数含 `userKey`（"用户可在登录后，于【用户中心】-【唯一标识码】中获取"） | 需登录后获取 userKey 才能调用 |

## 三、许可条款（详情页"法律声明/开放协议"modal 原文摘录，2026-08-14 抓取）

1. 免费：现阶段用户有权免费获取网站所有政务数据资源，享有**非排他使用权**，可自由利用、自由传播与分享（不得违反国家相关法律规定）。
2. 署名：成果中须注明来源为"**北京市公共数据开放平台**"；应用情况需通过网站**备案**。
3. 交通领域数据开放遵循《北京市交通出行数据开放管理办法(试行)》相关要求。
4. 免责：提供方对数据完整性、准确性、及时性不作担保，用户损失自行承担。
5. 网站内容所有权归北京市人民政府所有。
6. 调用**地图 API** 时须在系统界面显著位置标注审图号（页面原文示例：审图号 GS(2011)6023号）。
7. FAQ：下载数据、在线调用 API 均"请先注册，只有成为本网站注册用户后，才可以获取相应的资源服务"。

完整法律声明原文见同目录 `legal-notice-extract.md`。
